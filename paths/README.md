# Ray-tracing paths

The files in this folder are path parameters (gains, delays, angles) extracted from nine city scenarios of the
DeepMIMO v3 dataset at 3.5 GHz. New York (`city_0_newyork`) is held out as the unseen city.

They are derived from DeepMIMO and are shared here for non-commercial research use only, with attribution, under the
same terms as the DeepMIMO v3 package (Creative Commons Attribution-NonCommercial-ShareAlike 4.0). They are not covered
by the MIT license of the code. If you use them, cite:

A. Alkhateeb, "DeepMIMO: A generic deep learning dataset for millimeter wave and massive MIMO applications,"
in Proc. Information Theory and Applications Workshop (ITA), 2019.
